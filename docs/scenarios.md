# Scenarios

## Mini dataset

A small golden fixture (~12–18 events, ~10–14 queries) proving benchmark correctness. Exercises direct recall, episodic recall, associative recall, temporal recall, knowledge update, future-data isolation, noise, and missing knowledge.

## Project Atlas (future)

Fictional software project evolving over ~60 simulated days. Target: 250–400 events, 80–120 queries across all capabilities.
